Claude Code + DeepSeek V4 Pro 安装教程

引言

Claude Code 是当前最强大的 AI Agent 之一，拥有极其优秀的 Harness 体系，能够在代码编写、项目管理、自动化工作流等场景中提供强力支持。但 Claude Code 原生依赖 Anthropic 的 API，对国内用户来说，直接使用存在两个痛点：价格偏高和网络不稳定。

而 DeepSeek V4 Pro 恰好解决了这两个问题。DeepSeek 作为国产大模型的佼佼者，在性价比上几乎没有对手——性能比它好的价格没它便宜，价格比它便宜的性能没它好。更重要的是，DeepSeek 在国内可以稳定直连使用，无需处理网络访问的问题。

将 Claude Code 的强大 Agent 能力与 DeepSeek V4 Pro 的高性价比、稳定访问相结合，可以说是目前国内开发者的最优解。本文将手把手带你完成从零安装到顺畅使用的全过程。

前置条件

本文使用的系统环境为 Windows 11，其他系统操作类似，可参考对应步骤。

安装 Node.js

通过 npm 下载是安装 Claude Code 最便捷的方式，也是本文推荐的方法。因此首先需要安装 Node.js（npm 随 Node.js 一起安装）。

下载与安装

  1. 打开 Node.js 官网：https://nodejs.org/
  2. 下载 LTS 版本（长期支持版，更稳定），推荐 v20 或以上
  3. 推荐下载安装包（.msi）而非压缩包，安装过程更省心
  4. 运行安装程序，安装路径默认为 C:\Program Files\nodejs，推荐一路保持默认（确保勾选 Add to PATH），否则需要手动配置环境变量

下文将以 <nodejsRoot> 指代 Node.js 安装根目录。如果你未修改路径，<nodejsRoot> 就是 C:\Program Files\nodejs。

DeepSeek V4 Pro 接入

什么是环境变量

在正式配置之前，先用大白话解释一下环境变量。

一句话概括：环境变量就是告诉系统”你要的工具放在哪里”。

你在终端输入 node -v，系统凭什么知道 node 在 C:\Program Files\nodejs\ 下面？就是靠环境变量。把路径告诉系统之后，你在任何位置打开终端，系统都能找到它。

在 Windows 中，环境变量分两种：

  • 用户变量：只对你这个账号生效
  • 系统变量：对所有账号都生效

一个你刚经历过的例子——Node.js。安装时我们勾选了 Add to PATH，它做了什么？打开看看：

  1. 搜索”编辑系统环境变量”，打开
  2. 点击”环境变量”
  3. 在系统变量中找到 Path，点击编辑

你应该能看到一行 <nodejsRoot>\（默认就是 C:\Program Files\nodejs\）。这就是 node -v 能正常执行的原因——系统知道去哪找它们。

💡 本文要设的 Claude Code 相关变量，放用户变量就够了。

搞懂了环境变量，接下来就动手配置。

配置 Claude Code 的 PATH

在前面安装 Node.js 时，我们修改了 npm 的全局安装路径，因此 Claude Code 被安装在了 <nodejsRoot>\node_global\node_modules\ 下。打开该目录，你能看到一个 @anthropic-ai 文件夹——这就是 Claude Code 本体。

回到上级目录 <nodejsRoot>\node_global\，你能看到两个文件：

  • Claude.cmd — 供 CMD 使用
  • Claude.ps1 — 供 PowerShell 使用

为了让系统在任何位置都能找到 claude 命令，我们需要将 <nodejsRoot>\node_global 添加到环境变量中。

  1. 搜索”编辑系统环境变量”，打开
  2. 点击”环境变量”
  3. 在用户变量中，找到 Path，点击编辑
  4. 新建一行，填入 <nodejsRoot>\node_global（例如 C:\Program Files\nodejs\node_global）
  5. 点击确定，逐级保存退出

💡 为什么放在用户变量而非系统变量？Claude Code 是你个人的工具，没必要让其他用户也能调用，放在用户变量即可。

验证配置：重新打开一个终端窗口，输入：

如果能正常输出版本号，说明 PATH 配置成功。

获取 DeepSeek API Key

Claude Code 本身不收费，但需要通过 API 调用大模型。本文使用 DeepSeek V4 Pro 作为后端模型，需要先获取 API Key。

  1. 打开 DeepSeek 开放平台：https://platform.deepseek.com/
  2. 注册账号并登录（支持手机号注册）
  3. 进入控制台，点击 API Keys → 创建 API Key
  4. 给 Key 起个名字（如 claude-code），创建后立即复制保存（Key 只显示一次）
  5. 在 充值/计费 页面充值，DeepSeek 采用按量计费，费用极低，充值 10 元够用很久

⚠️ API Key 务必妥善保管，不要泄露或提交到公开仓库。下一步配置中会用到它。

总结

本文带你完成了三件事：

  1. 安装 Node.js 并配置 npm — 包括镜像源、全局路径等，为后续操作打好基础
  2. 安装 Claude Code — 一行命令搞定
  3. 配置 Claude Code — 设置 PATH 环境变量让 claude 命令全局可用，再通过 settings.json 对接 DeepSeek V4 Pro，将最强 Agent 跑在国产性价比最高的模型上

整个流程走下来，从零到能用的耗时不超过半小时。你获得了一个兼具强大 Agent 能力和高性价比 API 的 AI 编程助手，无需处理网络访问问题，国内直连稳定使用。
