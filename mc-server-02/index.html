MC联机开服教程（二）：联机方式——局域网、内网穿透与IPv6直连

第 1 篇我们聊了联机和开服的区别。如果你选了联机路线——也就是你当主机、朋友来你的世界玩——那这一篇就是你的实操手册。

本文覆盖三种联机方式，由易到难排列：

  • 局域网联机：同一个 WiFi，零配置
  • 内网穿透：朋友在外地，用 FRP 打通网络
  • IPv6 直连：有公网 IPv6 就能直接连

读完这篇，选一种适合你情况的方式，跟着操作就能连上。

前置工作：知道你的局域网 IP 和端口

无论哪种联机方式，你都需要知道两样东西：

  • 你的局域网 IP：你电脑在你家路由器下的内网地址
  • 游戏端口：MC 对外暴露的端口号

查局域网 IP

打开命令提示符（按 Win + R，输入 cmd，回车），输入：

找到你正在使用的网络适配器（通常是「以太网适配器」或「无线局域网适配器 Wi-Fi」），看 IPv4 地址 那一行，类似 192.168.1.105 或 10.0.0.8——这就是你的局域网 IP。

查游戏端口

进入 Minecraft → 按 Esc → 对局域网开放，聊天栏会显示：

🎮 本地游戏已在端口 xxxxx 上开放

记下这个端口号，每开一次游戏端口都不一样。

方法一：局域网联机（同在屋檐下）

这是最简单的情况：你和朋友连着同一个 WiFi。

Java 版

  1. 主机：进入存档 → 按 Esc → 对局域网开放 → 记下聊天栏显示的端口号
  2. 主机：把你的局域网 IP 告诉朋友（比如 192.168.1.105）
  3. 朋友：进入游戏 → 多人游戏 → 直接连接 → 输入 192.168.1.105:端口号

例如：主机 IP 是 192.168.1.105，端口是 55230，朋友就输入 192.168.1.105:55230

基岩版

更简单——进入存档后，同 WiFi 下的朋友在好友列表里就能看到你的世界，直接点加入就行。

连不上？检查防火墙

很多时候局域网连不上，罪魁祸首是 Windows 防火墙把连接拦了。最简单的验证办法：临时关掉防火墙试试。

⚠️ 这只是验证，不是长期方案。如果关闭防火墙后能连上，说明你的问题是防火墙配置。去 控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙，把 Java（javaw.exe）的两个勾都打上。

方法二：内网穿透（朋友不在身边）

当你和朋友不在同一个网络环境——你在家，他在学校、公司或另一个城市——你们之间隔着运营商的路由器，局域网的方法就行不通了。

为什么不能直接连？

你的电脑在路由器的 NAT（网络地址转换） 后面。简单理解：

你家的路由器有一个公网 IP（世界上的门牌号），而你电脑只有一个内网 IP（家内部的房间号）。外面的人只知道门牌号，不知道房间号——除非你主动告诉他们怎么走。

内网穿透，就是帮你把”房间号”告诉外面的朋友。

方案 A：Sakura FRP（推荐，免费省心）

Sakura FRP 是目前国内最流行、对新手最友好的内网穿透服务，免费额度足够联机用。

第一步：注册并创建隧道

  1. 去 Sakura FRP 官网 注册账号
  2. 进入管理面板 → 创建隧道
  3. 按以下参数配置：
参数 值
隧道类型 TCP
隧道名称 MC联机（随便填）
本地 IP 127.0.0.1
本地端口 你游戏的端口号（在 MC 聊天栏查看）
隧道节点 选离你最近的

创建完成后，面板会显示隧道的连接地址和端口，比如 example.cn:12345——这就是朋友要连的地址。

第二步：启动隧道

  1. 下载 Sakura FRP 启动器（管理面板里有下载链接）
  2. 打开启动器 → 登录 → 点「开启隧道」

隧道状态变绿（已连接），就说明打通了。

第三步：朋友连接

把你的连接地址和端口（例如 example.cn:12345）发给朋友，他在 MC 多人游戏 → 直接连接中输入即可。

怎么找到我的连接地址？
在 Sakura FRP 管理面板的隧道列表中，查看「连接地址」列。格式通常是 节点域名:远程端口。

💡 Sakura FRP 免费版节点推荐使用”枣庄多线”，速度较快。

方法三：IPv6 直连（如果能用，体验最好）

IPv6 是一个比较新的网络协议，它的最大优势是：每台设备都有独立的公网地址，不再需要 NAT。

就是每台设备在全球互联网上都有自己唯一的地址，不像 IPv4 那样大家挤在一个公网 IP 后面。

如果你和朋友的网络都支持 IPv6，那么联机就和局域网一样简单——直接连 IP 就行。

怎么检查自己有没有 IPv6？

打开 test-ipv6.com，结果会直接告诉你。如果显示「你的 IPv6 地址是 xxxx」，说明你有公网 IPv6。

怎么通过 IPv6 联机？

  1. 主机进入 MC → 对局域网开放 → 记下端口号
  2. 主机查自己的 IPv6 地址：

找到 IPv6 地址（临时 IPv6 地址），类似 240e:3b0:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx。注意看临时那个，而不是永久地址。

  1. 朋友在 MC 多人游戏 → 直接连接 → 输入 [IPv6地址]:端口号

IPv6 地址在 MC 里要用 方括号 包起来！例如：
[240e:3b0:17c:2c20:1234:5678:90ab:cdef]:55230

IPv6 的常见问题

朋友连不上？

  • 检查朋友的网络是否也支持 IPv6（手机热点通常有 IPv6）
  • 检查 Windows 防火墙是否拦截了 Java
  • 检查路由器是否有 IPv6 防火墙规则拦截了入站连接

我没有 IPv6 怎么办？

  • 大部分 4G/5G 手机热点自带 IPv6，可以让主机开热点
  • 部分宽带运营商默认开启 IPv6，去路由器后台看看（光猫管理页面通常有 IPv6 开关）
  • 如果实在搞不到 IPv6，退回方法二——内网穿透一样好用

三种方式对比

方式 适用场景 门槛 需要额外软件 稳定程度
局域网 同 WiFi 零 无 ⭐⭐⭐
内网穿透 异地联机 较低 Sakura FRP 或自建 FRP ⭐⭐～⭐⭐⭐
IPv6 直连 双方都有 IPv6 需要运营商支持 无 ⭐⭐⭐

一句话建议：同 WiFi 用局域网，异地优先试 Sakura FRP，IPv6 能用就用。

接下来？

联机搞定了，如果你只是想和朋友一起玩，这篇就是你的终点站。

如果你想要一个 24 小时在线、不需要你在线的服务器，那你要走的是开服路线——继续看第 3 篇：服务器选择。
